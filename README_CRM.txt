LeadPilot - Landing page connectée CRM

Le fichier principal est: index.html

Connexion CRM:
1. Ouvre index.html dans un éditeur de code.
2. Cherche cette ligne:
   const WEBHOOK_URL = "REMPLACE_ICI_PAR_TON_WEBHOOK_CRM";
3. Remplace REMPLACE_ICI_PAR_TON_WEBHOOK_CRM par ton URL webhook Make, Zapier ou GoHighLevel.
4. Redéploie le fichier sur Netlify.

Champs envoyés:
- source
- submitted_at
- name
- company
- email
- phone
- industry
- message
- page_url

Recommandation:
Utilise Make.com ou Zapier comme pont entre la landing page et ton CRM.
